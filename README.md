# Anatomy of Pace
**A quantitative framework for physiological telemetry.**

### Mission
This laboratory is dedicated to the deconstruction of trail running. Our objective is mathematical precision in analyzing pace degradation, terrain tax (TI), and biomechanical efficiency. 

### Lab Principles
*   **Data-Driven:** All conclusions are anchored in raw telemetry from .fit files.
*   **Clinical Aesthetic:** Visualizations are functional, not decorative. 
*   **Ghost Authority:** Analysis precedes personal narrative. The algorithm indicates; we execute.

### Toolbox
*   **Engine:** Python 3.x
*   **Core Libraries:** `pandas`, `numpy`, `matplotlib` (for F1-style telemetry visualization).
*   **Workflow:** .fit → Data Cleaning → TI-Calculation → Visualization.
